# Plataforma de Nutrição

Projeto desenvolvido com o objetivo de aprofundar conhecimentos em desenvolvimento de software, arquitetura e boas práticas de código, aplicado a um contexto real da área da nutrição.

## 🎯 Objetivo do Projeto
Desenvolver uma plataforma voltada para profissionais de nutrição, baseada em necessidades reais do dia a dia clínico, com foco em código limpo, organização e escalabilidade.

## 🧠 Contexto
O projeto surgiu a partir da colaboração com uma nutricionista, trazendo funcionalidades alinhadas à prática profissional.

## ⚙️ Funcionalidades Implementadas
- Cálculo de IMC (Índice de Massa Corporal)
- Classificação do estado nutricional
- Estrutura modular baseada em princípios SOLID

##  Arquitetura e Boas Práticas
- Separação de responsabilidades
- Código orientado a domínio
- Facilidade para testes e manutenção
- Preparado para evolução de regras de negócio

##  Tecnologias Utilizadas
- C#
- .NET
- Entity Framework (planejado)
- PostgreSQL / MongoDB (planejado)

## 🔮 Próximos Passos
- Cadastro de pacientes
- Histórico nutricional
- Planos alimentares
- Autenticação e controle de acesso

## 📌 Observações
Projeto em desenvolvimento contínuo, utilizado como laboratório prático para evolução técnica.
